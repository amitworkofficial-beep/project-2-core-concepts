# Project 2 - Core Concepts and Skills

## Student Performance Analyzer

This project was developed as part of Project 2 of the Data Science & Analytics Internship.

The project demonstrates fundamental programming and data analysis concepts through a simple Student Performance Analyzer.

## Concepts Covered

- Variables and data types
- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- Error handling
- Basic data analysis
- Average calculation
- Finding maximum and minimum values
- Code organization and documentation

## Features

The program:

1. Stores student information and marks.
2. Calculates the average marks.
3. Determines each student's performance category.
4. Identifies the student with the highest marks.
5. Identifies the student with the lowest marks.
6. Displays a clear performance report.

## Sample Result

Average Marks: 82.8

Highest Marks: Priya - 91

Lowest Marks: Rahul - 72

## How to Run

Make sure Python is installed.

Open the project folder in a terminal and run:

    python main.py
